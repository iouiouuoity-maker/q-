# FearMap GitHub Pages

Бұл буманың ішіндегі файлдарды GitHub repository түбіріне жүктеңіз.

Алдымен `assets/js/ai.js` файлындағы `AI_API_URL` тұрақтысына осы жоба үшін жаңадан жарияланған Cloudflare Worker URL-ін жазыңыз. Толық нұсқаулық бір деңгей жоғары орналасқан `README.md` файлында берілген.

Сайт сегіз жеке беттен тұрады: басты бет, кітапхана, карта, салыстыру, шығарма қосу, AI-анализ, әдеби детектив және прогресс. Бес мысал карточкасы бар, бірақ кітапхана олармен шектелмейді: `add-work.html` арқылы кез келген кітап пен кейіпкерді енгізуге болады. Қосылған карточкалар `library.html`, `map.html` және `compare.html` беттерінде бірден пайда болады әрі осы браузерде сақталады.
